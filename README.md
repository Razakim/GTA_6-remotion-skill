# GTA VI Remotion Skill

Le projet Remotion est dans [`elmaccato/`](./elmaccato/). Il produit des vidéos explicatives sur GTA VI et contient le moteur de composition, le skill de réalisation et la bibliothèque de médias.

## Démarrer le studio

```bash
cd elmaccato
npm install
npm run dev
```

## Repères

- Consignes de réalisation : [`elmaccato/.agents/skills/remotion-explainer-video/SKILL.md`](./elmaccato/.agents/skills/remotion-explainer-video/SKILL.md)
- Moteur d’animations en couches : [`elmaccato/src/motion/`](./elmaccato/src/motion/)
- Plan de scènes courant : [`elmaccato/src/data/scenes.json`](./elmaccato/src/data/scenes.json)
- Catalogue des médias : [`elmaccato/public/assets/catalog/media.json`](./elmaccato/public/assets/catalog/media.json)
